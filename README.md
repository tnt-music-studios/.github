# TNT Music Studios

Organization-wide files for the repositories under
[tnt-music-studios](https://github.com/tnt-music-studios).

| File | What it is |
|---|---|
| [CONTRIBUTING.md](CONTRIBUTING.md) | How contributions to any of our repositories are licensed. GitHub shows it on every repository that has no contributing guide of its own. |
| [CLA.md](CLA.md) | The Individual Contributor License Agreement, which every contributor accepts once through CLA Assistant on their first pull request. |
| [CLA-ENTITY.md](CLA-ENTITY.md) | The Entity Contributor License Agreement, for an employer or other organization that owns its people's contributions. |

How to build, test and submit a change to one project is in that project's own repository.
